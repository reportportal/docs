# Ginkgo 

There is an agent to integrate [Ginkgo v2](https://github.com/onsi/ginkgo) with ReportPortal.

Ginkgo is a testing framework for Go. The integration enables sending Ginkgo test execution results, logs, attachments, and related test data to ReportPortal.

Community contribution: This integration was created and shared by a ReportPortal contributor. We appreciate the contribution to the ReportPortal ecosystem.

[Installation guide](https://github.com/That-geeky-shree/report-portal-go/blob/main/agent-go-ginkgo/README.md)
