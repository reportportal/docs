# Integration via plugin

Users can enhance ReportPortal by adding additional integrations with:
* [Jira Server](../plugins/bug-tracking/AtlassianJiraServer.mdx)
* [Jira Cloud](../plugins/bug-tracking/AtlassianJiraCloud.mdx)
* [Rally](../plugins/bug-tracking/Rally.mdx)
* [Azure DevOps](../plugins/bug-tracking/AzureDevOps.mdx)
* [GitLab](../plugins/bug-tracking/GitLab.mdx)
* [Monday](../plugins/bug-tracking/Monday.mdx)
* [Sauce Labs](../plugins/other/SauceLabs.mdx)
* [E-mail server](../plugins/notifications/EmailServer.mdx)
* [Slack](../plugins/notifications/Slack.mdx)
* [Telegram](../plugins/notifications/Telegram.mdx)
* [LDAP](../plugins/authorization/LDAP.mdx)
* [Active Directory](../plugins/authorization/ActiveDirectory.md)
* [Okta SAML](../plugins/authorization/SamlProviders/OktaSaml.mdx)
* [Azure SAML](../plugins/authorization/SamlProviders/AzureSaml.mdx)
* [JUnit](../plugins/import/JUnit.mdx)
* [RobotFramework](../plugins/import/RobotFramework.mdx)

<MediaViewer src={require('./img/Integrations.png')} alt="Integrations with our test automation results dashboard" />

If you're keen on incorporating ReportPortal with other external systems, and can't find the necessary tab in the Project Settings, please refer to the [Plugins section](../plugins/index.md) in our documentation for guidance. Our test reporting tool integrates seamlessly, allowing for a streamlined connection with external systems.

The integrations can be added at a global level, applicable for all projects on an instance, in the "Administrate" section. Alternatively, they can be specific to a project and can be configured in the Project Settings.

For those who require a different configuration to other projects, or want to integrate only their specific project with an external system, the following steps could be followed:

1. Log into ReportPortal as a `PROJECT MANAGER` or `ADMINISTRATOR`

2. Navigate to Project settings > Integrations

3. Click on one of the shown integration panels

4. Click on the "Add Project integration" button.

Performing these steps will unlink your current project from the global settings and initiate your own configuration.

<MediaViewer src={require('./img/ProjectIntegration.png')} alt="Create Project Integration" />

:::note
When a project uses its own integration configuration, changes to the instance-wide integration do not overwrite the project settings. The project continues to use its project-level configuration until it is reset to global settings.
:::

To revert to the global settings, click the button titled "Reset to global settings". This action will erase your settings, and the integration will revert to using the global settings.

Remember, you can always reset to the global settings.
