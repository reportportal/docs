# All Organizations

"All organizations" page can be accessible using sidebar.

On this page, Admin can see a list of all organizations on the instance, while other users only see the organizations they are assigned to.

<MediaViewer src={require('./img/all-organizations/AllOrganizations1.png')} alt="How to find All Organizations page in our qa automation dashboard" />

The page provides next information:

* **Organization name**<br />
By clicking on the organization name user is redirected to Organization level. In case the organization name is too long, an ellipsis appears at the end. Upon hovering over the ellipsis, a browser tooltip appears with full organization name.
* **Organization type icon**<br />
    * **Internal** – organizations, created directly in ReportPortal
    * **Personal** – organizations, created for each user upon user account creation in ReportPortal. The creation of personal organizations on the instance is configured by Admin in Server Settings>Authorization configuration
    * **Synched** – organizations, created via synchronization of ReportPortal and external systems.

"All Organizations" page allows:

* to view a list of all organizations on the instance (Admin) or only assigned organizations (other roles)
* to export the list of organizations (Admin), with or without applied filters
* see all the events of all the projects within a single organization (Admin)
* to assign/unassign users from organization
* to rename an organization
* to delete an organization

## Controls

In the header of the "All Organizations" page, the following controls are displayed if at least one organization is available to the user:

* Search icon – available for all roles
* Filter icon – available for Admin, Manager
* Sorting – available for all roles
* Panel view – available for all roles
* Table view – available for all roles
* Export button – available for Admin

By clicking the "Export" button, you can download the list of organizations to your computer.

<MediaViewer src={require('./img/all-organizations/AllOrganizations9.png')} alt="Export on All Organizations page" />

## Create organization

:::note
Organization management is available only when the Organizations [premium feature](../../../premium-features/) is enabled.
:::

To create an organization from the "All Organizations" page:

1. Log in as Admin.
2. Navigate to "All Organizations" page.
3. Click on the "Create Organization" button.
4. Enter organization’s name.
5. In the modal window, click on "Create" button.

<MediaViewer src={require('./img/all-organizations/AllOrganizations10.png')} alt="Create Organization" />

## Activity

On the "All organizations" page, Admin can see all the events of all the projects within a single organization.

For that:

1. Log in as Admin.
2. Navigate to "All organizations" page.
3. Click on meatball menu on organization panel.
4. Click on "Activity" option.

<MediaViewer src={require('./img/all-organizations/AllOrganizations11.png')} alt="Activity option on All Organizations page" />

All events are displayed in a table consisting of the following columns:

* **Time** – when the event occurred.
* **Project Name** – the project in which the event took place (optional if the event is not project-related).
* **Subject Type** – who performed the action. Possible values: User / Application / Rule.
* **Subject Name** – ```<login>``` / ReportPortal / Pattern Analysis.
* **Action** – the action that was performed.
* **Object Type** – the type of object on which the action was performed.
* **Object Name** – the name of the object on which the action was performed.
* **Old Value** – the previous value before the change.
* **New Value** – the updated value after the change.

<MediaViewer src={require('./img/all-organizations/AllOrganizations12.png')} alt="Activities on All Organizations page" />
