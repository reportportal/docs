# Organizations plugin

Organizations plugin is our [premium feature](/getting-started/features/Organizations).

The Organizations plugin introduces a two-level structure with organizations and projects, enabling teams to group multiple projects under one organization for easier management. It simplifies administration, supports consistent reporting across projects, and helps companies scale their testing setup efficiently.

## Upload plugin

1. Log in to ReportPortal as Admin.
2. Navigate to Instance plugins page.
3. Click "Upload Plugin" button.
4. Add .jar file and click ‘Upload’ button.

## Disable plugin

1. Log in to ReportPortal as Admin.
2. Navigate to Instance plugins page.
3. Find "Organizations" plugin.
4. Click the toggle to turn it off.

## Uninstall plugin

1. Log in to ReportPortal as Admin.
2. Navigate to Instance plugins page.
3. Find "Organizations" plugin and click on it.
4. Click "Uninstall" button and confirm your choice.
