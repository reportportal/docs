# Quality Gates plugin

Quality Gates plugin is our [premium feature](/getting-started/features/QualityGates).

It speeds up CI/CD pipelines by automatically checking builds against customizable quality criteria and providing instant feedback on release readiness.

## Upload plugin

1. Log in to ReportPortal as Admin.
2. Navigate to Instance plugins page.
3. Click "Upload Plugin" button.
4. Add .jar file and click "Upload" button.

## Disable plugin

1. Log in to ReportPortal as Admin.
2. Navigate to Instance plugins page.
3. Find "Quality Gates" plugin.
4. Click the toggle to turn it off.

<MediaViewer src={require('./img/QualityGatesPlugin.png')} alt="Manage Quality Gates plugin" />

## Uninstall plugin

1. Log in to ReportPortal as Admin.
2. Navigate to Instance plugins page.
3. Find "Quality Gates" plugin and click on it.
4. Click "Uninstall" button and confirm your choice.
