# Reporting and metrics in ReportPortal

## Test automation reports in ReportPortal

With ReportPortal, you can boost your software quality by obtaining detailed
test automation reports to monitor test execution, identify issues, and analyze trends for continuous enhancement through collaborative dashboards in test reporting.

| Report                        | Description | Widget |
|-------------------------------| --|-------------|
| **Summary report**            | An overview of test execution: tests run, passed, and failed. | [Overall statistics](./OverallStatistics.mdx) <br/> <br/> [Launches table](./LaunchesTable.mdx) <br/> <br/> [Passing rate summary](./PassingRateSummary.mdx) |
| **Detailed test case report** | Specific details about individual test cases: status (Passed/Failed), execution time, and associated issues/errors. | [Most failed test-cases table (TOP-50)](./MostFailedTestCasesTableTop50.mdx) <br/> <br/> [Flaky test cases table (TOP-50)](./FlakyTestCasesTableTop50.mdx) <br/> <br/> [Unique bugs table](./UniqueBugsTable.mdx) |
| **Trend analysis report**     | The trends in test results over time. | [Most failed test-cases table (TOP-50)](./MostFailedTestCasesTableTop50.mdx) <br/> <br/> [Flaky test cases table (TOP-50)](./FlakyTestCasesTableTop50.mdx) <br/> <br/> [Failed cases trend chart](./FailedCasesTrendChart.mdx)<br/> <br/> [Passing rate summary](./PassingRateSummary.mdx) |
| **Failure analysis report**   | The failed test cases and their details. | [Most failed test-cases table (TOP-50)](./MostFailedTestCasesTableTop50.mdx) <br/> <br/> [Flaky test cases table (TOP-50)](./FlakyTestCasesTableTop50.mdx) <br/> <br/> [Failed cases trend chart](./FailedCasesTrendChart.mdx)<br/> <br/> [Most popular pattern table (TOP-20)](./MostPopularPatternTableTop20.mdx) |
| **Execution history report**  | The historical data of test runs. | [Passing rate summary](./PassingRateSummary.mdx) <br/> <br/> [Launches duration chart](./LaunchesDurationChart.mdx) <br/> <br/> [Investigated percentage of launches](./InvestigatedPercentageOfLaunches.mdx) <br/> <br/> [Test-cases growth trend chart](./TestCasesGrowthTrendChart.mdx) |

## QA and test automation metrics in ReportPortal

ReportPortal provides various metrics for improving quality assurance and the overall effectiveness of the testing process.

| Metric                            | Description | Widget |
|-----------------------------------| --|------------|
| **Passed/Failed rates**               | The percentage of test cases that are passing or failing during test execution. | [Passing rate per launch](./PassingRatePerLaunch.mdx) <br/> <br/> [Passing rate summary](./PassingRateSummary.mdx) <br/> <br/> [Launch statistics chart](./LaunchStatisticsChart.mdx) <br/> <br/> [Overall statistics](./OverallStatistics.mdx) <br/> <br/> [Launch execution and issue statistic](./LaunchExecutionAndIssueStatistic.mdx) |
| **Execution time**                | The time it takes to execute test suites or individual test cases. | [Launches duration chart](./LaunchesDurationChart.mdx) <br/> <br/> [Most time-consuming test cases widget (TOP-20)](./MostTimeConsumingTestCasesWidgetTop20.mdx) |
| **Defect density**                | The number of defects found per unit of code or test case provides a quantitative perspective on the software quality of a given system under test. | [Component health check](./ComponentHealthCheck.mdx) |
| **Test case success rate**        | The percentage of successful test cases out of the total executed highlights the reliability of the test. | [Passing rate per launch](./PassingRatePerLaunch.mdx) <br/> <br/> [Passing rate summary](./PassingRateSummary.mdx) <br/> <br/> [Launch statistics chart](./LaunchStatisticsChart.mdx) <br/> <br/> [Overall statistics](./OverallStatistics.mdx) <br/> <br/> [Launch execution and issue statistic](./LaunchExecutionAndIssueStatistic.mdx) |
| **Regression test effectiveness** | The capability of regression tests to detect new defects or issues. | [Overall statistics](./OverallStatistics.mdx), with special defect type for issues found in regression.  <br/> <br/> [Unique bugs table](./UniqueBugsTable.mdx), with special defect type for issues found in regression. |
| **Error/failure distribution**    | The frequency and distribution of test failures across defined components or modules within a given system under test. | [Component health check](./ComponentHealthCheck.mdx) |
