# Folders

Folders are used to organize test cases into a hierarchical structure, making it easier to manage, navigate, and reuse test assets. Folders can contain test cases as well as nested subfolders, allowing teams to group tests by feature, module, release, or any other organizational criteria.

Any user with project access can view the list of available folders and test cases within a folder.

## Search folders

Any user with project access can search folders.

## Create folder

To create folder:

1. Log in as Admin, Manager or user with edit permissions.
2. Navigate to "Test Case Library" page.
3. Click on the "Create Folder" button.
4. Enter folder name.
5. Click "Create" button.

<MediaViewer src={require('./img/CreateFolder.png')} alt="Create Folder" />

To create subfolder:

1. Log in as Admin, Manager or user with edit permissions.
2. Navigate to "Test Case Library" page.
3. Click on the "Create Folder" button.
4. Enter subfolder name.
5. Turn the "Create as subfolder" toggle ON.
6. Select parent folder.
7. Click "Create" button.

## Duplicate folder

To duplicate folder:

1. Log in as Admin, Manager or user with edit permissions.
2. Navigate to "Test Case Library" page.
3. Click the "More actions" (•••) icon next to the folder.
4. Select "Duplicate folder" option.
5. Modify folder name (optional).
6. Turn the "Move to root directory" toggle ON or select folder destination.
7. Click "Create" button.

## Rename folder

To rename folder:

1. Log in as Admin, Manager or user with edit permissions.
2. Navigate to "Test Case Library" page.
3. Click the "More actions" (•••) icon next to the folder.

## Move folder

To move folder:

1. Log in as Admin, Manager or user with edit permissions.
2. Navigate to "Test Case Library" page.
3. Click the "More actions" (•••) icon next to the folder.
4. Select "Move folder to" option.
5. Select "Move to existing folder" or "Create new folder".
6. Fill in the required fields and turn the toggle ON, if necessary.
7. Click "Move" button.

## Add folder to test plan

To add folder to test plan:

1. Log in as Admin, Manager or user with edit permissions.
2. Navigate to "Test Case Library" page.
3. Click the "More actions" (•••) icon next to the folder.
4. Select "Add to Test Plan" option.
5. Select test plan from the dropdown.
6. Click "Add" button.

## Drag&drop folder

To drag&drop folder:

1. Log in as Admin, Manager or user with edit permissions.
2. Navigate to "Test Case Library" page.
3. Click the drag-and-drop icon next to the folder.
4. Drag the folder to a valid drop target.
5. Select "Move", or "Duplicate", or "Cancel".

<MediaViewer src={require('./img/DragAndDrop.png')} alt="Drag and drop folder" />

## Delete folder

To delete folder:

1. Log in as Admin, Manager or user with edit permissions.
2. Navigate to "Test Case Library" page.
3. Click the "More actions" (•••) icon next to the folder.
4. Select "Delete" option.
5. Click "Delete" button.
