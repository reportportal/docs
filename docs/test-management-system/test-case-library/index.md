# Test Case Library

The Test Case Library is a centralized repository used to create, organize, maintain, and manage all test cases within a project. It enables teams to structure test assets, reuse test cases across test plans and launches.

"Test Case Library" page can be accessible using sidebar on project level.

How to get started with Test Case Library?

1. Create folder.
2. Create or import test cases.
3. Use tags to categorize test cases.

<MediaViewer src={require('./img/TestCaseLibrary.png')} alt="Test Case Library in the sidebar" />

Import is available even if no folder exists yet. Test cases can't exist outside a folder, so one is created automatically and all imported test cases are placed in it.

On the Test Case Library page, you can find the complete list of test cases that later become planning scope items in Test Plans and executable items in Manual Launches.

Build and maintain the test case library before starting milestone planning or manual execution.

The test case library lets you:

* organize your test cases with folders
* create and maintain test cases
* <span>import test cases using a CSV template</span>
* search and filter test cases
* perform bulk updates
* add selected test cases to Test Plans or Manual Launches
* review a test case's change history
