# Bulk operations

Bulk operations provide a way to manage multiple test cases at once by applying the same action to a selected set of tests.

## Bulk add test cases to test plan

To add selected test cases to test plan:

1. Log in as Admin, Manager or user with edit permissions.
2. Navigate to "Test Case Library" page.
3. Bulk-select test cases.
4. Click "Add to Test Plan" button.
5. Select test plan.
6. Click "Add" button. 

## Bulk add test cases to launch

To add selected test cases to launch:

1. Log in as Admin, Manager or user with edit permissions.
2. Navigate to "Test Case Library" page.
3. Bulk-select test cases.
4. Click "Add to Launch" button.
5. Select "Add to existing launch" or "Create new launch".
6. Fill necessary fields.
7. Click "Add" button.

## Bulk move test cases

To move selected test cases:

1. Log in as Admin, Manager or user with edit permissions.
2. Navigate to "Test Case Library" page.
3. Bulk-select test cases.
4. Click "Move to Folder" button.
5. Select "Move to existing folder" or "Create new folder".
6. Fill necessary fields.
7. Click "Move" button.

## Bulk duplicate test cases

To duplicate selected test cases:

1. Log in as Admin, Manager or user with edit permissions.
2. Navigate to "Test Case Library" page.
3. Bulk-select test cases.
4. Click "Duplicate to Folder" button.
5. Select "Duplicate to existing folder" or "Create new folder".
6. Fill necessary fields.
7. Click "Duplicate" button.

## Bulk change priority for test cases

To change priority for selected test cases:

1. Log in as Admin, Manager or user with edit permissions.
2. Navigate to "Test Case Library" page.
3. Bulk-select test cases.
4. Click "Change priority" button.
5. Select priority.
6. Click "Save" button.
